# Demo Web Shop QA Testing Project

## Overview
Manual and automated testing of Demo Web Shop (E-commerce app).

## Scope
- Login / Register
- Product Search
- Add to Cart
- Update Cart Quantity
- Checkout

## Tools
- Cypress (Automation)
- Manual Testing (Test Cases & Bug Reports)

## How to Run
1. `npm install`  
2. `npx cypress open`  
3. Run test files

## Outcome
Validated core E-commerce workflows and created automated scripts with bug reporting.
